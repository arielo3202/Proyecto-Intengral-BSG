# Especificación de Requisitos y Criterios de Aceptación (`REQUIREMENTS.md`)
**Rol Responsable:** Product Owner / Business Analyst & Application Security Architect

---

## 1. Historias de Usuario y Casos de Uso Priorizados (MoSCoW)

| ID | Prioridad | Rol | Historia de Usuario | Criterios de Aceptación (Given / When / Then) |
| :--- | :---: | :--- | :--- | :--- |
| **HU-01** | **MUST** | Usuario / Admin | Como empleado de TechCorp LATAM, quiero consultar políticas internas, procedimientos y soporte TI en un chat multi-turno que recuerde el contexto de mi sesión (`session_id`). | **Dado** un usuario autenticado con JWT válido,<br/>**Cuando** envía preguntas consecutivas con el mismo `session_id`,<br/>**Entonces** el Root Agent ADK conserva el contexto entre turnos e invoca la `@tool` `search_corporate_policies` o `create_it_support_ticket`. |
| **HU-02** | **MUST** | Usuario | Como empleado con rol `usuario`, debo recibir únicamente respuestas claras del asistente sin ver jamás datos técnicos, tokens, latencias, trazas ReAct ni costos. | **Dado** un JWT con `role="usuario"`,<br/>**Cuando** consume `/api/v1/chat/message` o intenta acceder a `/api/v1/admin/*`,<br/>**Entonces** el payload de chat omite a nivel de backend cualquier campo técnico y los endpoints `/admin/*` devuelven `HTTP 403 Forbidden`. |
| **HU-03** | **MUST** | Admin | Como Administrador (`role="admin"`), quiero visualizar el registro de auditoría inmutable (JSONL + cadena SHA-256), las trazas ReAct y el dashboard de uso y costos en tiempo real (E6 integrado). | **Dado** un JWT con `role="admin"`,<br/>**Cuando** abre el panel de administración Pixel Art,<br/>**Entonces** visualiza métricas de tokens, latencia, estado del Circuit Breaker, comparativa de modalidades (2.1, 2.2, 2.3) y verifica la integridad de la cadena de hashes SHA-256. |
| **HU-04** | **MUST** | Admin | Como Administrador, quiero exportar los registros de auditoría y métricas de costos en formatos **PDF** y **CSV** desde el frontend. | **Dado** un usuario con `role="admin"`,<br/>**Cuando** presiona los botones `[EXPORTAR PDF]` o `[EXPORTAR CSV]`,<br/>**Entonces** descarga el archivo generado por FastAPI con sello de integridad criptográfica y resumen ejecutivo. |
| **HU-05** | **MUST** | Sistema | Como sistema financiero-empresarial, debo limitar el consumo a **10 requests/minuto por usuario** y activar un **Circuit Breaker** hacia Ollama (`llama3.2:3b`) si Vertex AI falla. | **Dado** un usuario que supera 10 solicitudes en 60 segundos,<br/>**Cuando** realiza la solicitud #11,<br/>**Entonces** recibe `HTTP 429 Too Many Requests` con cabecera `Retry-After`. Si Vertex AI acumula 3 errores, el Circuit Breaker pasa a `OPEN` y responde con Ollama. |
| **HU-06** | **SHOULD** | Usuario / Admin | Como analista corporativo de TechCorp LATAM, quiero consultar comparativas de acciones e indicadores cuantitativos (SMA, EMA, RSI, Volatilidad, Sharpe) validados contra datos atrasados, precios anómalos o inconsistencias de moneda. | **Dado** un prompt que solicita análisis de tickers (ej. `AAPL`, `MSFT`, `MELI`),<br/>**Cuando** el agente invoca la `@tool` `analyze_stock_comparative`,<br/>**Entonces** valida homogeneidad de divisa, cobertura, frescura de precios y anomalías antes de retornar los indicadores. |
